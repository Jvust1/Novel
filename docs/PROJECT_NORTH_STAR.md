# Project North Star

## 目标

打造一个真正适合中文网络小说和长篇连载的 AI 写作助手。它应更像“懂故事的共同作者 + 连续性编辑 + 文风编辑”，而不是文本续写器。

最终用户可以：

1. 给出题材、设定、总纲、卷纲或章纲。
2. 系统理解故事承诺、核心冲突、人物弧与伏笔。
3. 将章纲拆成有因果、有选择、有转折、有后果的场景计划。
4. 在人物知识边界和状态约束下写出完整章节。
5. 根据用户提供的代表文本，建立可解释、可混合的 Style DNA。
6. 写完后自动检查连续性、人物失真、情节硬推、AI 腔与参考文本近似复用。
7. 作者可随时介入、修改、锁定事实和重写局部，不被“全自动流水线”绑架。

## 质量优先级

从高到低：

1. **故事是否想继续看**：冲突、悬念、承诺、节奏、章末拉力。
2. **人物是否像活人**：欲望、矛盾、选择、代价、关系变化、说话差异。
3. **因果是否成立**：事件不能只因为大纲说“下一步发生 X”就发生。
4. **长篇是否一致**：时间、地点、能力、物品、关系、秘密、认知边界、伏笔。
5. **语言是否自然**：不模板化、不均匀、不处处解释、不滥用修辞。
6. **环境是否有效**：只写对行动、感受、信息、节奏有价值的环境。
7. **风格是否统一且有辨识度**：来自可解释的 Style DNA，而非作者名提示词。

## 明确不做

- 不以“无人值守生成百万字”为首要目标。
- 不把长上下文长度当成长篇一致性的替代品。
- 不为了所谓文学感自动堆砌形容词、意象、天气和心理说明。
- 不把所有人物写成同一种机智、克制、善于总结的 AI 声音。
- 不把参考小说正文直接混入生成提示词并做句级仿写。
- 不把 API Key、Token、参考书正文或用户未公开手稿提交到 GitHub。

## 完成标准

一个版本只有同时提升 **情节、人物、连续性、语言自然度**，并能由真实章节 A/B 评测证明，才算有效进步。单纯增加 Agent 数量、RAG 组件或提示词长度不视为进步。
