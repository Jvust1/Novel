# Novel Product Spec v0.1

## 当前产品形态｜2026-09-12

当前产品是 ChatGPT 中的长篇写作流程与持久故事档案。下列故事、人物、大纲、Style DNA、审校和连续性能力仍是目标；原工作台页签改为对话任务，API Key 配置不适用于当前路线。
具体执行见 `docs/CHATGPT_WRITING.md`：恢复档案 → 场景计划 → 作者确认 → 正文 → 审校/局部修订 → 作者接受版本 → 提取并确认记忆 → 保存进度。
`writing/story_state.json` 为尚未填写的单部小说起点。软件原型的既有代码不代表这些对话门槛已有程序自动校验。

## 核心工作区

### 1. 故事项目
- 书名、题材、受众、基调、目标字数/章数
- Story Bible：世界规则、主题、核心冲突、不可违背事实
- 总纲 / 卷纲 / 章纲

### 2. 人物
每个角色至少包含：
- 身份与外在特征
- 核心欲望 / 当前目标
- 恐惧 / 缺陷 / 自我欺骗
- 秘密
- 与主要角色的关系状态
- 说话习惯与语言层级
- 已知事实 / 未知事实 / 错误认知
- 当前资源、能力、伤病和位置
- 最近一次关键变化

### 3. 大纲扩写
输入一句或一段章纲后，先生成场景计划：
- POV
- 场景目标
- 冲突来源
- 信息释放
- 人物选择
- 代价
- 状态变化
- 伏笔推进/回收
- 章末钩子

用户确认或编辑后再进入正文。

### 4. 章节写作
支持三种模式：
- 快速草稿：计划 → 正文
- 标准：计划 → 正文 → 连续性/文风审校
- 精修：计划 → 正文 → 双审校 → 局部修订 → 再审

### 5. Style Lab
用户可加入多份代表文本，系统提取：
- 句长均值/波动
- 短句与长句比例
- 段落长度与波动
- 对白占比
- 叙述 vs 动作 vs 心理 vs 环境的倾向
- POV 与叙事距离
- 修辞/意象密度
- 标点与节奏偏好
- 词汇层级、口语度、书面度
- 情绪表达方式：直述 / 行为 / 生理 / 留白
- 信息密度与解释倾向

多个 profile 可设置权重，形成项目 Style DNA。

### 6. AI 味审校
检测并提示：
- 同类句式连续出现
- 过多“仿佛 / 似乎 / 微微 / 缓缓 / 不由得”等弱化或模板词
- 频繁“不是……而是……”等总结式修辞
- 动作后紧跟情绪解释
- 每段长度过度均匀
- 人人说话都完整、机智、会总结
- 环境描写与剧情无关
- 心理描写重复解释已经显而易见的情绪
- 段尾频繁上价值、总结意义

审校输出应给出位置、原因和局部改法，不自动全章洗稿。

### 7. 连续性
至少追踪：
- 人物位置、时间、伤病、物品、能力
- 人物知道什么 / 不知道什么
- 关系变化
- 伏笔 active / resolved
- 世界规则
- 事件因果链

## UX 原则
- AI 先给结构化建议，用户可编辑，再生成正文。
- 用户可以锁定人物/事实/段落，后续不得擅改。
- API Key 只存在会话或本地 `.env`，不上传。
- 参考文本和未公开正文默认保留在本地/Drive。
