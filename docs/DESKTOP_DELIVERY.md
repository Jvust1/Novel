# Novel Windows 写作工作台交付候选版

解压完整便携包，运行 Novel.exe，保留 _internal 文件夹。无需另装 Python。使用已有 Edge 或系统浏览器，程序仅监听 127.0.0.1；控制窗口退出会停止服务。关闭前先保存页面中的编辑。

## 已连接的写作流程
故事设定、独立锁定事实、人物卡与知识边界、Style DNA、场景计划确认、正文生成、编辑审校、精修后复审、作者确认记忆候选后回写。可不连接任何模型，直接在“稿件与备份”中编辑、保存、查看历史、导出稿件或整个项目。

已修正计划类型缺失、旧章摘要重排、零摘要预算、作品切换状态串用、锁定事实混写、过期计划误用、记忆人物状态未落盘和路由式精修缺少复审。模型 API 仅在你触发生成等操作时使用。

## 本地数据和恢复
默认数据目录 `%LOCALAPPDATA%\NovelDesktop\data`。章节重写前保留旧稿的哈希版本；JSON/正文原子保存；记忆回写前保存恢复快照。稿件和模型回复不会自动公开上传。
“稿件与备份”提供项目 ZIP；恢复只允许新项目名，拒绝越界、重复和超限文件。项目切换在当前进程中隔离并保留未保存的草稿，但进程关闭前仍应保存。

## 模型选择
默认 Base URL 是本机 Ollama 的兼容端点 `http://127.0.0.1:11434/v1`；模型名需填写本机真实安装名称。本包不含模型、不自动下载、不从本机失败转发云端。也可自行明确配置授权的兼容端点；API Key 仅保留在当前页面会话，不写入项目文件。对应服务的费用和授权由你自行决定。

## 验收边界
代码测试不等于所有模型真实文笔、长篇一致性或盲评分已验收。原有 frozen benchmark 不变，本轮不伪造真人评分或真实模型结果；生成文本和记忆候选必须复核。Windows CI 验证也不代表你的设备已经完成验收。EXE 未做商业签名。无字体、参考小说全文或模型权重附送。

完整测试与发行身份见 Verification.zip、release.json、SHA256SUMS.txt。
