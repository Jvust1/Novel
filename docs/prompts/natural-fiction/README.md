# 中文小说文风提示包

本包将两个已核验 MIT 上游的少量编辑规则，接入 Novel 的中文长篇工作流：事实保护、样本声音校准、上下文判断、修订前后核对。小说专用的视角、人物知识、伏笔和局部补丁协议由 Novel 新写。它改善可审读的表达质量，不是 AI 检测器，不承诺检测通过率或小说商业结果。

## 使用顺序

1. 在当前作品明确一个主类型，可选一个辅类型，从 [类型文风卡](GENRE_PROFILES.md) 取候选配置；已有作者决定、作品配置和锁定内容优先
2. `Context → Scene Plan` 后使用 [01 写前](01-writing-before.md)，整理文风、人物声线与事实锁；只有 TASK 明确要求时才接着起草
3. `Draft → Review` 使用 [02 审校](02-editorial-review.md)，给出定位、阅读影响和最小修改范围，允许零修改
4. `Local Repair → Re-review` 使用 [03 局部修订](03-local-repair.md)，交候选片段与逐项差异，核对事实锁及相邻段接缝
5. 作者采用且复核通过后，才进入项目既有的 Memory Update / Release 流程

在 GPT 中可粘贴对应阶段提示与明确的输入材料；在有文件读取能力的工作流中可引用对应文件。此包只是可复用提示与文风配置，不自动注册工具、改变应用代码、启动模型调用或写回正式稿。工作流的真实加载/调用由接入方显式完成，不得把“文件已放进仓库”称为“运行时已启用”。

### 最小调用示例

```text
按 docs/prompts/natural-fiction/02-editorial-review.md 审读以下章节。
主类型：悬疑；辅类型：都市/日常。采用本书已确认的叙述声音。
本次只审文风，兼查修改可能碰到的事实/知识/伏笔风险，不改剧情。
STYLE_PROFILE：[本书文风卡]
CONTEXT / FACT_LOCK：[已确认资料；没有的部分注明未提供]
SCENE_PLAN：[本章计划]
DRAFT：[本章正文]
请先指出值得保留的表达，再列有定位的必要修改；没有问题可原样保留。
```

当前《退潮前的失物招领》第一章只能作为本次悬疑场景的试读样本，不代表用户已选择全书冷峻、口语或悬疑风格。读取时观察到的近距离第三人称、动作/对白推进和物件线索可以形成临时测试卡；使用前须与最新章稿核对。这不是已完成的质量评测。

## 保护与范围

- 保留 [Project North Star](../../PROJECT_NORTH_STAR.md) 的质量目标，不替换已有有效文风规则
- 文风随类型与作品选择变化，不采用跨类型统一口吻；人物保持各自声音
- 修辞按上下文判断，不强删排比、比喻、短句、心理活动或必要说明
- 没有参考书时不声称已提取参考 DNA；未来只学高层规律，不借用特色句段和事件链
- 未确认的新线索、动机、时序和事实不能借文风修订进入正文；候选稿不得自动成为 canon
