# 可组合的类型文风卡

这些是 Novel 新写的候选配置与原创微型例句，不是上游现成类型模板，也不是用户已确定的文风偏好。覆盖常见大类，不穷尽子类型；每本书选择适合自己的配置，不把所有类型混进同一章。例句仅说明表达差异，其中人物与事件不得进入正在写的故事。

## 组合方式

每张实际使用的 STYLE_PROFILE 都要写清：

- 主类型与读者期待；可选辅类型及它具体贡献的场景效果
- 叙述人称、主要视角、允许的叙事距离；已有设定优先
- 基础语气与情绪外露程度
- 句段节奏、动作/对白/内心/环境各自承担的作用（无需固定配比）
- 语汇层级、时代与职业词边界、意象使用方式
- 主要人物各自的关注点、应答习惯和避讳
- 场景局部变化；本书有意保留与避免的表达

主类型决定基本阅读体验，辅类型只补充所需效果。比如“科幻 + 悬疑”保留同一叙述声音，用已给出的技术约束组织线索；“仙侠 + 言情”可以在亲密场景放慢观察，但不忽然换时代用语或让人物忘记修行代价。章节切换不意味着重置声音。

有作者样本时，从多段不同场景提取上述高层规律；把观察写成候选卡，标明样本范围与例外。不能复制某一本参考作品的特色表达、人物网络或事件顺序。无样本时按本书主类型提出暂定卡，不冒充已匹配作者。

## 1. 都市 / 日常

- 候选基调：贴近人物生活经验，可温暖、轻快、辛辣或沉静；不默认全部冷硬
- 距离与节奏：人物近景和生活场面相接；日常对话可以快，难以启齿的决定可留停顿
- 语汇与意象：贴合职业、年龄、地域与交往方式；幽默来自处境，避免旁白不断抖机灵
- 声线：同事谈执行和麻烦，家人未必直说关心；差异须由已有关系支持
- 复核点：生活细节是否确有材料支持？是否把所有人写成同一种网络口吻？

原创微例：工资到账，陆遥先把欠的午饭钱转了。母亲问够不够花，他拍了桌上的两份菜，没把计算器拍进去。

## 2. 言情 / 关系向

- 候选基调：亲密关系中的欲望、试探与防守；可以明亮直给，也可以克制含蓄
- 距离与节奏：按既定视角贴近细微判断；对白、停顿和内心各有位置，不强制只写动作
- 语汇与意象：有选择地强化当事人在意的感官信息；意象随人物经验，不自动堆香味、眼神和心跳
- 声线：谁先伸手、谁转移话题、谁故意客气，要与关系阶段一致
- 复核点：有没有靠误会拖延代替真实选择？润色情绪是否提前揭露另一方内心？

原创微例：“伞给你。”她说。“那你呢？”“楼上还有。”他抬头看了一眼已经熄灯的办公室，没再问，把伞往她那边移了移。

## 3. 悬疑 / 推理

- 候选基调：可好奇、紧迫、冷静或带黑色幽默；悬念来自信息差，不靠每段预告危险
- 距离与节奏：跟随既定调查视角；观察、判断、验证区分清楚，已知可重读而不假装新发现
- 语汇与意象：物件和动作准确；带证据作用的颜色、顺序、时间不能为文采改变
- 声线：问话、回避、解释各有目的；疑点不等于人物有罪
- 复核点：读者获知顺序是否保持？有没有将猜测写成事实，或删掉公平解谜所需的普通细节？

原创微例：“你走时门锁着？”“锁着。”她把照片转过来。门闩在里面。他看了一会儿，才问照片是什么时候拍的。

## 4. 玄幻 / 仙侠

- 候选基调：成长、惊奇、冲突与代价；可昂扬、飘逸、诙谐或苍凉，依作品选择
- 距离与节奏：关键选择贴近人物，宏观天地描写按已定叙述权限展开；战斗、领悟、日常不使用同一节奏
- 语汇与意象：术法、境界和器物称谓一致；壮阔意象有落点，不以形容词替代力量规则
- 声线：年资、门派关系、处世方式影响措辞；不能人人开口都是威压与冷笑
- 复核点：华丽描写是否暗中提升战力、追加能力或免除原定代价？

原创微例：剑上的霜只结到第三寸便停了。师父没有催。阿砚重新握紧剑柄，把方才借来的那口气一点点还回去。

## 5. 奇幻

- 候选基调：异世界的陌生感与人物可理解的需要并存；神话感、冒险感或童话感择其一为底色
- 距离与节奏：世界通过人物当下行动显现；必要概括可保留，不在每件器物出现时停下解释百科
- 语汇与意象：陌生专名节制且一致；比喻来自本世界可成立的经验
- 声线：文化差异落实到礼节、禁忌和谈判方式，避免只靠奇怪口音
- 复核点：新奇修辞是否被读成新增魔法规则？日常需求是否被设定说明淹没？

原创微例：守桥的石像收下铜币，却没有让路。“这是昨天的价。”它说。米拉把面包掰下一半：“今天的早饭。”

## 6. 科幻

- 候选基调：技术约束下的人的选择；可冷峻、乐观、荒诞或抒情，不默认实验报告腔
- 距离与节奏：观察、假设与测量结果分层；解释放在人物需要理解或采取行动的位置
- 语汇与意象：技术词保持准确，必要时用人物熟悉的尺度表达；未知仍可未知
- 声线：不同职责关注不同风险，专业角色也有独立态度，不人人负责讲课
- 复核点：润色是否改变单位、数量、通讯延迟或能力边界？比喻有没有被误写成机制？

原创微例：回信还要四个小时。林澈把“收到”删了，重新录了一句：“冷却泵停了。我先去修。”录完，她才拿起工具。

## 7. 历史 / 架空历史

- 候选基调：在制度、人情与时代限制中行动；可平实、典雅或诙谐，避免一律伪文言
- 距离与节奏：人物当下经验与必要时代背景相接；叙述者所知不能无故变成人物所知
- 语汇与意象：称谓、物件和制度遵循已确认时代；架空差异要有设定依据
- 声线：身份与关系影响礼数，但角色不是官衔说明书
- 复核点：是否凭空补史实或使用不合设定的现代概念？语言“古雅”是否掩盖动作不清？

原创微例：主簿把名册往前推了半寸。“再添一户。”里正没接笔，只指了指窗外等米的人：“添谁，您说个名字。”

## 8. 武侠

- 候选基调：行动、承诺和江湖关系；可豪迈、疏朗、诙谐或悲凉，由本书确定
- 距离与节奏：交手时动作与空间清楚，胜负之间保留人的判断；行旅和对坐可以舒展
- 语汇与意象：招式称谓服务读者理解，兵器、方位与伤势稳定；留白不能遮掉关键因果
- 声线：守诺、逞强、试探各有说法，不人人用同一种江湖套话
- 复核点：局部改句是否改变先后手、可达距离、伤势或承诺的真实含义？

原创微例：刀停在酒碗上方，碗里的酒还在晃。赵七收了手：“这一刀算我请。”对面的人把碗端起来，一口没喝。

## 9. 恐怖 / 惊悚

- 候选基调：安全感逐步失效；可压抑、荒诞、民俗或直面威胁，避免统一低语腔
- 距离与节奏：保持视角感官边界；普通动作与异常相邻，是否突然加速服从本场景
- 语汇与意象：少数清晰异常比泛化阴森更可感；可以直写惊惧，不要求每次换成生理反应
- 声线：人在压力下的求证、否认或求助仍需符合既有人物
- 复核点：是否为了吓人新造异象、破坏规则或替角色确认尚未知的真相？

原创微例：她把门后的鞋摆正。洗完手回来，那双鞋又朝着屋里。她没有再碰，先给独居的母亲打了个电话。

## 使用后的复核

把本书实际采用的卡交给 02 审校，检查文本是否兑现了选定声音，而非检查是否命中某种类型的所有套路。读者期待与事实锁冲突时先报告，不能为了“更像悬疑/更像仙侠”改掉故事。
