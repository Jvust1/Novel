# 开篇切入点 × 代入感专项（Novel）

## 适用与输入
用于新书首章、第一场，或作者明确说“开篇无聊/代入感弱”时；后续章节可借用局部场景技巧，但不强行当作全书第一章。按 `Story Bible → 已确认章计划 → 人物知识与读者揭示白名单 → 现有正文` 读取；缺哪项写清，不把故事档案和来自参考书的表达当作可自动填空的素材。

## 第一步：诊断读者为什么还没进入故事
对现有开篇给出原句/段落定位，逐项回答：
1. **跟谁走？** 前几段能否稳定认出 POV 与其可感知范围？读者是否知道自己身处何处、眼前正在发生什么？缺定位不是“神秘”。
2. **他现在想干什么？** 具体到可执行的当下小目标；不必第一句提出终极宿命，也不必强加追车、凶案或打斗。
3. **什么在阻止？** 人、制度、关系、时间、误判、环境等应有可见影响；安静场面也能有紧迫或尴尬。
4. **失败有什么近期后果？** 让读者在乎人物而非只被异象吸引；不把虚假危机、反复惊叹号当吸引力。
5. **场面能摸到吗？** 至少有服务人物行动/判断的一处可感知细节和相应反应，避免五感清单、旁白讲履历、镜头无端离开人物。
6. **这一场变了什么？** 主角作出选择、丢掉机会、改变判断或关系，开头承诺的题材体验须与后续真实情节相符。

不把这六问量化成作品分数；标出最多三个最影响阅读的问题，保护已有好段落。若只有摘要而无正文，明确只能审计划。

## 第二步：为未确认的开篇提候选，不直接改定稿
在不新增 Canon / 人物秘密 / 证据 / 能力 / 时间事实的边界内，提出 **2–3 种有实质差别** 的切入位置：
- **临门一脚**：人物正在做一件小而重要的事，阻力已出现。
- **关系碰撞**：一次有目的的要求/拒绝揭示人物处境；不靠吵架热闹冒充冲突。
- **已存在的异常或代价**：人物注意到已授权事实中的反常之处，并必须作反应。

每案用四行描述“首个画面 / 当下目标 / 阻力与代价 / 本场状态变化”，标明依据哪些已确认来源，及为何更贴合该类型的读者期待。无真实依据的方案只能标为待作者决定，不能混入正文。既有作者已确认计划不得默认替换；提案等作者确认版本。

## 第三步：实际写场景，而不是描述剧情
仅在已有有效场景计划且允许起草时：从*人物必须行动或判断*的节点切入，尽量少让开场先替读者补课。先给读者足以追踪的身份/方位/处境，再留下一个有意义的问题；“信息差”不能变成“看不懂”。让细节改变行动、选择或关系；允许直接叙述必要的过渡，不要机械化 `show, don't tell`。内心想法与身体反应须属于该 POV；对话有未说出口的目的，角色声线按已有资料区分。节奏由场景压力调节，不按五感清单填充描写，不设首句长度、感官数量和必须反转配额。

## 第四步：开篇审校与局部修订
把开头与已确认的章节承诺逐项对照：地点/视角是否清楚；人物为何要做眼前事；阻力是否具体；读者知道的代价；承诺是否真能在后文兑现；首场前后有无变化。给“原句定位 → 阅读损失 → 最小局部修订范围”。不擅自添加悬念、反派、案件、旁白真相；只允许根据当前 `plan_revision + draft_revision` 修正，改稿后重新审校。好的开篇不要求凭惊险制造刺激，安静人物场面同样有效。

## Novel 的执行顺序
章计划 `plan_messages` 先确定合理切入，`draft_messages` 在实际正文写出当下局面，`review_messages` 给带定位的问题，`repair_messages` 只改获准片段。GPT 对话路线见 `docs/GPT_WRITING_ENTRY.md` 与 `docs/prompts/natural-fiction/01-writing-before.md`。本 Skill 文件不会被任意 agent 自动加载；项目运行时仅已显式接入的提示文本生效，模型是否遵循须以实际稿件验证。
